## 決定事項

| # | 論点 | 決定 |
|---|---|---|
| V2-1 | アイコン | `lucide-react` を導入する。代替案は個別の SVG をコンポーネントとして管理する方式。パッケージ本体は ISC、一部の Feather 由来アイコンは MIT。[Lucide のライセンス](https://lucide.dev/license) |
| V2-2 | 表示文言 | 全画面を Figma v2 の平易な日本語にそろえる。ナビゲーションは「ホーム」「イベント」「地点」「オープンキャンパス」「地図」「公開前チェック」「公開履歴」「操作記録」。画面では「日時」「公開をやめる」「公開中・変更あり」「公開停止」「公開できない問題」「公開する前に直すこと」「会場の説明」「アプリでの見え方」などを使う。URL パスと API・DB の内部識別子は維持する。 |
| V2-3 | 適用範囲 | 新しいアプリの外枠と共通部品を全体に適用する。ホーム（O01）とイベント（E01〜E05）の実装後、v2 に描かれていない既存画面も段階的に v2 の見た目と文言にそろえる。 |
| V2-4 | ホームの未公開変更 | O01 の「まだ公開していない変更」は「公開前チェック」と同じ5領域を扱う。イベント、開催回、カテゴリ、地点、地図の5行を常に表示する。 |
| V2-5 | 公開中の内容に戻す | E02 の「公開中の内容に戻す」は確認ダイアログを開き、確認後に専用 API `POST /api/events/{id}/revert-to-published` を呼ぶ。公開中の内容を新しい下書き Revision として保存し、操作記録に残す。 |
| V2-6 | 会場と時刻の入力 | E03 の会場追加には、日時の欄に置くインライン検索欄のみを使う。名称・別名・建物・階・ID で検索できるようにする。時刻はブラウザー標準の `<input type="time">` を使い、見た目を v2 にそろえる。 |
| V2-7 | 開催回の初期値と環境表示 | E04 の新規イベント作成では、開催回が1件だけなら自動選択し、複数なら未選択で始める。環境バッジ（`session.environmentLabel`、12 UI-22）はサイドバーの「Nexus Studio」ロゴ直下に継続して表示する。 |
| V2-8 | 実装の順序 | v2 刷新は PR 1〜7 に分け、共通基盤、ホーム、イベント、その他の既存画面の順に進める。Map Data エディタ本体（24 E・F）とタイムスケジュール取り込み（35 v01）はそれぞれ別に進める。 |
| V2-9 | デザインの正本とトークン | `CLAUDE.md` の見た目の正本を Figma v2 に切り替える。画面を確認して色・余白のトークンを整備し、操作部品の識別に必要な境界などは WCAG 1.4.11 の 3:1 を満たす。Figma Variables の数値が共有されたら反映する。[WCAG 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast) |
| V2-10 | フォントとウェイト | `@fontsource/geist`（400/700）・`@fontsource/line-seed-jp`（400/700）・`@fontsource/geist-mono`（400）をセルフホスト導入する（SIL OFL 1.1、外部 Google Fonts CDN 依存を廃止）。代替案は Google Fonts CDN またはシステムフォントのみとする方式。ウェイトは 400（Regular）と 700（Bold）の 2段階に限定し、`font-synthesis-weight: none` で偽ボールドを防ぐ。数値・時刻・件数・版番号には `tabular-nums` を適用する。 |
| V2-11 | トークンとコントラスト | 刷新した Figma v2 Variables（色23種・寸法13種・影2種）を正本とし、本文は WCAG 2.2 AA（4.5:1 以上）、入力欄境界 `--color-border-input`（`#878792`）は WCAG 1.4.11（3.0:1 以上、白地 3.55:1）を満たす。`--color-danger`（`#b91c28`）× `--color-danger-subtle`（`#fef2f2`）は 5.89:1 で AA 準拠。 |
| V2-12 | フラット App Shell とバランス密度 | 灰背景＋角丸白シート（`PageSheet`）を廃止し、220px サイドバー（`#f7f7f8`）＋1px `#dcdce1` 仕切り＋白キャンバス（`#ffffff`）＋54px トップバー（1px `#ececef` 下線）＋`#f7f7f9` 右プレビューのフラット構成とする。行 44px・標準操作/入力 36px・小操作/セグメント 30px・本文 14px・角丸 4/6/8px。 |
| V2-13 | 状態表示と一覧・編集の共通表現 | 状態表示（`Status / Label` `37:224`）は 6px ドット（公開中・警告・エラーは塗り丸、未公開は白抜き丸）＋文言とし、ホーム／一覧の淡青ピルボタンと行クリックの重複を廃止する。イベント編集（`E02`〜`E05`）は展開中枠のみ 1px 枠線、日時操作は `⋯` メニュー、時間方式・参加案内は 30px セグメント切替、下部管理は `公開履歴を見る ↗`＋折りたたみ `詳細管理（元に戻す・公開停止）`、未公開地点注意帯は検索結果に未公開候補がある場合のみ表示する。 |
| V2-14 | 未設計画面の進め方 | `O01`・`E01`〜`E05` 以外の画面（`R01`・地点・オープンキャンパス・地図・公開前チェック・公開履歴・操作記録）はテキスト仕様だけで実装せず、先に Figma モックアップを作成・確認してから実装する。 |
