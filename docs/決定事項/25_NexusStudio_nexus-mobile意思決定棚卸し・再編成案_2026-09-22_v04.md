## 1. 重大な訂正：#24〜#54（E3〜E6、31件）は既にSwiftUI前提へ書き換え済みだった

### 1.1 何が誤りだったか

v01・v02・v03はいずれも「Issue #24〜#54（31件）がExpo/React Native前提のまま残っている」「最大の影響範囲」と記述し、v03 §6では「最大28件」を要確認としていた。**これは誤りである。**

実際にGitLabから全87件を取得して確認した結果、**31件全件が2026-09-07の「工程3 承認済み差分」で既にSwiftUI前提へ書き換え済み**であることが判明した。各Issueは次の構造を持つ。

```markdown
## 概要
SwiftUI向けの地図描画方式を比較し、採用理由と描画の土台を記録する。
Expo SDK 54 / react-native-mapsを実装前提にしない。

## 工程3 承認済み差分（2026-09-07）
Expo SDK 54/react-native-maps前提をSwiftUI向け描画方式の比較・採用へ変更。

<details>
<summary>変更前の技術前提・依存（履歴）</summary>
変更前の概要：
依存追加と地図描画の土台を作る。Expo SDK 54 での構成方法を確定する。
</details>
```

本文（履歴の`<details>`ブロックを除く）は**SwiftUIを前提とし、Expoへの言及は「実装前提にしない」という明示的な否定文としてのみ現れる**。旧内容は折りたたみ済みの履歴として保全されており、削除されていない。

### 1.2 検証方法

単純な文字列検索（`Expo`／`react-native`の有無）では、この否定文を「Expo前提が残っている」と誤判定する。今回は次の手順で訂正した。

1. 全31件の本文から`<details>...</details>`ブロックを除去
2. 除去後の本文に`Expo`／`react-native`が残るかを再検索
3. 残った4件（#24, #25, #38, #46）を全文確認し、いずれも「〜を実装前提にしない」「〜は旧方式の履歴とする」という**否定・除外の文脈**であることを目視確認

### 1.3 結果

| 対象 | 件数 |
|---|---|
| #24〜#54のうち「変更前の技術前提（履歴）」を持つ | 9件（#24, #25, #27, #37, #38, #40, #45, #46, #47） |
| 上記のうち履歴を除いた本文に`Expo`/`react-native`が残る | **4件**（#24, #25, #38, #46）—**いずれも否定文** |
| 本文にExpo/RNへの実質的な依存が残る | **0件** |

| どちらにも言及がない（純粋にデータ・UI設計） | 8件（#32, #33, #36, #39, #41, #42, #49〜#54等） |

**#24〜#54は書き換え作業が不要である。** v01〜v03の「31件の書き換えが必要」という記述、および25 v03 §6の「SwiftUI前提へ書き換え：31」「現在の状態確認が必要：最大28」という分類を撤回する。

### 1.4 #45について（v03からの継続確認）

v03 §7で「#45のタイトルが『Home / Map / Info に再定義する』のまま残っている可能性が高い」としていたが、**これも誤りだった**。実際のタイトルは次のとおり、既に正しい。

### 1.5 この訂正が意味すること

利用者が2026-09-22に示した診断——「決めていなかったのではなく、決めた結果が正本（`v1.0-scope.md`）へ戻る経路が動いていなかった」——は、想定していた以上に正確だった。**Issue側の記述は2026-09-07時点で既にSwiftUI・4タブへ全面的に更新されており、ズレていたのは`v1.0-scope.md`・`README.md`・`ios-native-migration-plan.md`・`parallel-issue-selection.md`という「文書側」だけだった。** これらは本日のTier 0作業で更新済みである（15 v02 / 25 v03参照）。

```bash

取得結果はスクラッチ領域に一時保存し、本書作成後は保持していない（機密情報ではないが、成果物として恒久化する必要がないため）。再取得が必要な場合は4.1のコマンドで同じ結果を得られる。

書き込み権限が実際に効かないことを、無害な操作で確認した。

```

{"error":"insufficient_granular_scope","error_description":"Access denied: This operation
requires a fine-grained personal access token with the following project permissions:
[Work Item: Update]."}
