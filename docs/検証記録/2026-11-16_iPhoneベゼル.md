# 2026-11-16 Events の iOS Preview：端末枠を iPhone 17 に替える

## 目的
手描きの「Generic iPhone Frame」を、Apple の製品ベゼル画像（手元にあるとき）と、同じ寸法の簡易フレーム（無いとき）に替える。ベゼル画像はリポジトリに入れない（README「iPhone のベゼル画像」）。

## 枠を使う画面
`src/pages/events/editor/PreviewPanel.tsx`（Events 編集画面の右側 iOS Preview。1280px 未満では `shell/SidePanel.tsx` で重ねて表示）だけ。ほかに手描きの枠は無い。

## 実測した寸法（`iPhone 17 - Black - Portrait.png`、1350×2760px）
| 項目 | 値 |
|---|---|
| 画面の切り抜き | x 72〜1277・y 69〜2690（1206×2622px = 402×874pt @3x） |
| 画面の角丸 | 約188px（実装は180px。ベゼル内側の不透明な縁の下に収まる） |
| Dynamic Island | x 488〜861・y 112〜219（374×108px。画像では不透明な黒） |
| 本体の外形 | 左右28px・上下26px の内側 |
| safe area（iPhone 17） | 上 62pt・下 34pt（画面幅に対する割合 `cqw` で余白にする） |

iPhone 17 / 17 Pro の各色は同じ切り抜き寸法だった（White・Pro Silver で確認）。

## 手順
DB と Docker が無い環境のため、実際の `PreviewPanel` を設計用サンプルで描く使い捨ての Vite ハーネス（コミットしない）で撮影した。表示幅 1000px、Studio はライトテーマのみ（ダークテーマは未実装）。

## 結果
| 画像 | 内容 |
|---|---|
| `2026-11-16_iPhoneベゼル/before_generic-frame.jpg` | 変更前（328×692px の手描き枠、論理393×852） |
| `2026-11-16_iPhoneベゼル/after_fallback-outline.jpg` | 変更後・ベゼル画像なし（CI・Docker と同じ表示） |

- ベゼル画像ありの表示も確認した（画面の内容がベゼルの切り抜きに一致し、角丸の外へ内容がはみ出さない。背景を一時的にマゼンタにして確認）。この写真は Apple の画像を含むため公開リポジトリには置かず、オーナーへ直接渡した。
- `npm run build`：画像ありでは `dist/local-bezels/` に原寸の PNG がそのまま入り、画像なしでは入らず参照も 0 件。
- `npm run typecheck`・`npm run lint`：成功。
